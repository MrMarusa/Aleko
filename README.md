# სუფრა /DISPATCH

Corporate Georgian lunch catering site for Tbilisi offices — daily dispatch menus, volume quoting, and a manager hub demo.

## Stack

- TanStack Start + React Router
- Vite 8
- Tailwind CSS v4
- Bun (preferred) or npm

## Develop

```sh
bun install
bun run dev
```

Or with npm:

```sh
npm install
npm run dev
```

App runs at `http://localhost:3000`.

## Scripts

| Command | Description |
| --- | --- |
| `bun run dev` | Dev server |
| `bun run build` | Production build |
| `bun run preview` | Preview built app |
| `bun run lint` | ESLint |
| `bun run test` | Vitest |

## Brand

Kraft `#D6C7B2`, cream `#F4EFE6`, garnet `#6E1414`, ink charcoal. Square corners, print-dispatch vernacular, bilingual KA/EN.
